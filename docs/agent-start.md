# Agent Startup Procedure

Whenever beginning a new coding-agent session:

1. Read `/AGENTS.md`.
2. Read `/HANDOFF.md`.
3. Read `/docs/current-state.md`.
4. Read `/docs/tasks.md`.
5. Read `/docs/decisions.md`.
6. Read any domain documentation relevant to the requested task.
7. Run `git status`.
8. Review recent commits.
9. Inspect the current diff if uncommitted changes exist.

Before making substantial changes, summarize:

- current objective
- current implementation state
- relevant architecture
- relevant constraints
- unfinished work
- known blockers
- intended next action

Do not redesign working systems merely because a different design is possible.

When repository documentation conflicts, identify the conflict explicitly.
